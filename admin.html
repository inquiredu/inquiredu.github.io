    GitHub connection

    Publishing saves projects.json to your Pages repository. GitHub needs a token that can write to that one repository.

    1. Open GitHub's new fine-grained token page.
    2. Under Repository access, choose Only select repositories and pick inquiredu.github.io. GitHub's default, Public repositories, is read-only and can't publish.
    3. Under Permissions, click Add permissions, choose Contents, then change its access from Read-only to Read and write. On older versions of the page, find Contents in the list and pick Read and write. Leave everything else as it is.
    4. Generate the token and paste it below.

    Already made a token that can't publish? Open your fine-grained tokens, choose it, click Edit, fix steps 2 and 3, and save. The token itself doesn't change, so you don't need to paste it again.
