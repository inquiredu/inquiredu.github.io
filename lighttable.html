Don’t have a key yet? Make one (about two minutes)
  1. Open GitHub’s new fine-grained token page. Name it inquiredu publishing.
  2. Repository access: choose Only select repositories and pick inquiredu.github.io and site-catalog.
  3. Permissions: add Contents and Actions, both set to Read and write. Leave everything else alone.
  4. Press Generate token, copy it, and paste it above. The same key unlocks Site settings.
